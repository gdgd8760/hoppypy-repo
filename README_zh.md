### 🎒 列表与字典（编程觉醒）

```python
# 用列表和字典构建任务系统 🗺️
quests = [
    {"name": "打印你的第一行代码", "reward": 100, "done": True},
    {"name": "构建待办事项列表",   "reward": 500, "done": False},
]

completed = [q for q in quests if q["done"]]
total_xp = sum(q["reward"] for q in completed)
print(f"📈 进度: {len(completed)}/{len(quests)} | 💰 经验值: {total_xp}")
```

### 🧩 整理乱数据（数据与文本工具）

```python
# 清理一份乱糟糟的报名表 🧹
raw = """name,email
  Alice ,ALICE@example.com
bob,bob@Example.com
  Alice ,alice@example.com"""

rows = raw.splitlines()[1:]          # 跳过表头
seen = set()
for row in rows:
    name, email = row.split(",")
    email = email.strip().lower()
    if email not in seen:            # 去掉重复的人
        seen.add(email)
        print(f"{name.strip().title()} <{email}>")
```
